# MPLADS source data

`MPLADS.csv` is a development snapshot of public MPLADS work records supplied for this build. It is not a live feed. The application records source freshness and supports later CSV ingestion with snapshot/change detection.

The current snapshot does not contain expenditure, physical-progress, expected-completion, district, or coordinate fields. Sentinel therefore does not fabricate those values or score those unavailable signals.
